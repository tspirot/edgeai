# Дообука Whisper-а и означавање

## 1. Скупљање парова

Циљ: неколико стотина одобрених парова (исечак звука, исправљен текст). За друге
мале језике толико је било довољно да WER падне са преко 48% на 12–45%
(Baniwa је успела са 1.373 снимка). То је досег једног разреда кроз годину.

```bash
govor korpus stanje        # прати „sati_odobreno“ и „prosecan_skor“
govor korpus izvoz -o parovi.tsv
```

## 2. Дообука (на рачунару са GPU, не на Jetson-у)

LoRA над `openai/whisper-large-v3` или `large-v3-turbo`:

- узорак: `parovi.tsv` (пут до WAV-а, исправљен текст),
- подела по ГОВОРНИЦИМА, не по исечцима — иначе модел научи глас, не говор,
- мала научна стопа, 3–5 епоха, рано заустављање по WER-у на издвојеним говорницима.

Извоз у CTranslate2 формат, па `asr.model_dir` на станици покаже на те тежине.

## 3. Провера да није „упеглао“ говор

После дообуке, пусти станицу на снимке које модел није видео и упореди
**просечан скор торлачности** пре и после:

```bash
govor prepisi kontrolni.wav                    # стари модел
govor prepisi kontrolni.wav -c novi.yaml       # дообучени
```

Ако је скор пао, дообука је померила модел ка стандарду — то је грешка, не
напредак. Циљ је да дообучени модел **боље** препише дијалекатске облике
(`лебац`, `човекат`, `съга`), не да их изглади.

## 4. Означавање морфосинтаксом (опционо, за веб)

**Torlak ReLDI Tagger** (github.com/bravethea/Torlak-ReLDI-Tagger-2019) даје
врсту речи и лему за торлачки, CRF модел, готове тежине. Улаз је један токен по
реду, празан ред = крај реченице; излаз је TSV (реч, MSD, лема).

```
# из корпуса → формат за означивач
python -c "from govor.korpus import Korpus; [print(w) or (i%1) for u in Korpus('korpus').unosi() for w in u.tekst_ispravljen.split()]"
```

Означени корпус је оно што рад Tang & Vuković (COLING 2025) користи за дообуку
модела који оцењује торлачност — затвара круг: правила издвоје кандидате, човек
исправи, означивач структурише, модел научи.
