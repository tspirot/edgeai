# Жива реч

Теренска станица која снима пиротски говор **тамо где интернета нема** — у кући
говорника — транскрибује на лицу места и одмах даје да се исправи. Пројекат
програма [Edge AI Пирот](https://edgeai.tsp.edu.rs), ради на Jetson Orin Nano.

> **Чет-бот који „зна“ пиротски је засебан, каснији веб пројекат.** Ова станица
> само прикупља грађу. Права вредност није модел него корпус који иза њега
> расте.

## Зашто баш на уређају

Пиротски говор (тимочко-лужнички дијалекат) део је **торлачке групе, коју UNESCO
води као угрожен језик**. Снимаш глас старе особе у њеној кући. Слање тога на
туђи сервер је тачно оно што се не сме. Ниједан други пројекат програма нема
тако чист разлог да буде офлајн.

## Три ствари које станица не сме

| правило | где стоји у коду |
|---|---|
| **Модел не измишља** — транскрипт је полазна тачка за исправку, не тврдња | `govor.OGRADA`, тест |
| **Речник не измишља** — свака одредница носи извор; непотврђено се исписује са оградом | `recnik.py`, тест `test_svaka_odrednica_ima_izvor` |
| **Приватност** — снимак остаје на уређају док говорник не одобри; извоз прескаче све без сагласности | `Korpus.za_doobuku`, тест |

## Мерење торлачности — правила, не модел

`crte.py` мери „колико је реченица пиротска“ преко правила (полугласник, /ѕ/,
аналитички компаратив по-/нај-, постпозитивни члан, изгубљено /х/, аорист,
футур са „че“…). Свака црта има пример, тежину и тест.

**Намерно је груба.** Поуздано препознавање дијалекта из текста тражи дообучен
модел — правила промаше и лажно погоде. Скор се тумачи као „вреди погледати“,
никад као пресуда. Служи да се издвоје јако дијалекатски сегменти за исправку и
да се провери да дообучени Whisper није „упеглао“ говор ка стандарду.

Замисао из: Tang & Vuković, „NLP for preserving Torlak“, COLING 2025.

## Постојећи алати које вреди укључити

- **Torlak ReLDI Tagger** (github.com/bravethea/Torlak-ReLDI-Tagger-2019) —
  CRF означивач врсте речи и леме за торлачки, са готовим моделом. Кад корпус
  нарасте, њиме се уноси означавају морфосинтаксом (`docs/oznake.md`).
- **Речник пиротског говора**, Драгољуб Златковић (Службени гласник, 2014) —
  ~10.000 одредница. `recnik.yaml` је почетни исечак.
- **Говорни корпус торлачког**, Вуковић и сар. — узор за формат.

## Хардвер

- NVIDIA Jetson Orin Nano Developer Kit (8 GB), напајање, хладњак
- добар USB микрофон (за старије гласове важнији него камера)
- слушалице — говорник чује свој снимак при исправци
- напајање из повербанка за рад на терену

Ради и на обичном рачунару. **Без модела и микрофона цео ланац ради са `--asr dummy`.**

## Инсталација

```bash
git clone https://github.com/tspirot/edgeai.git
cd edgeai/projekti/ziva-rec
python -m venv .venv
source .venv/bin/activate        # Windows: .venv\Scripts\activate
pip install -e .                 # језгро: црте, речник, корпус, тестови

pip install -e ".[zvuk]"         # микрофон (sounddevice)
pip install -e ".[asr]"          # faster-whisper
```

## Покретање

```bash
govor oceni "Съга че идем да купим лебац"    # оцена реченице, без звука
govor devices                                 # микрофони

# додај говорника (пре снимања — сагласност је обавезна за извоз)
govor korpus govornik baba-mara --inicijali "М. Ј." --selo Крупац --godiste 193x --saglasnost

govor prepisi snimak.wav --asr dummy          # препис + оцена по сегменту
govor ispravi snimak.wav --govornik baba-mara # препис па упис исправки у корпус
govor korpus stanje                            # бројке
govor korpus odobri 000042                     # говорник одобрио овај унос
govor korpus izvoz -o parovi.tsv               # (wav, текст) за дообуку
```

## Ланац

```
микрофон ──► снимак (16 kHz, остаје на уређају)
              │
   Whisper (large-v3-turbo, int8) ──► ЛОШ препис
              │                        (стандардни модел меље дијалекат)
   crte.py ──►│ оцена торлачности по сегменту, речничке белешке
              ▼
     говорник исправља сегмент по сегмент
              │
     корпус: (исечак звука, исправљен текст, ко, сагласност, скор)
              │
     govor korpus izvoz  ──► дообука Whisper-а (LoRA, на рачунару с GPU)
              │
       дообучене тежине  ──► назад на станицу
```

## Границе и обазривост

- **Каталог/речник није поуздан** док га говорник не потврди. Ознака „НЕПОТВРЂЕНО“
  се сме уклонити само уз име особе и село.
- **Оцена торлачности је груба** — за издвајање, не за пресуду.
- **Прикупљање података ЈЕСТЕ пројекат**, не припрема за њега. Тражи сагласност,
  стрпљење кроз месеце и људе који стварно говоре пиротски. Ако то нема ко да
  води, боље не почињати — половичан корпус угроженог језика је гори од никаквог.

## Тестови

```bash
pip install -e ".[dev]"
pytest
```

60 тестова, без модела и микрофона: издвајање и оцена црта, скор на стандардним
и дијалекатским реченицама, речник и његове ограде, корпус (говорници, уноси,
одобравање, извоз само са сагласношћу), цео ланац са `dummy` ASR-ом.
