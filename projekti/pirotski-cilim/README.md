# Шара у духу пиротског ћилима

Уређај поред школског разбоја који ради две ствари **на самом уређају**, без
облака: чита шару са ћилима и објашњава је, па на основу скице ученика компонује
нову шару по правилима заната — и избаци је као **картон за ткање**, мрежу коју
ткаља стварно чита. Пројекат програма [Edge AI Пирот](https://edgeai.tsp.edu.rs).

## Пре свега: како се ово сме звати

**„Пиротски ћилим“ је регистрована географска ознака** (Завод за интелектуалну
својину, 2003). Право на то име имају само овлашћени произвођачи који раде по
прописаном елаборату — вертикални разбој, техника клечања, вуна праменке за
основу, прописане шаре и боје. Заштићено је име и репутација, не појединачан
цртеж.

Зато овај програм свој излаз доследно зове **„шара у духу пиротског ћилима“**.
То пише у `cilim.OGRADA`, исписује се уз сваки предлог и има свој тест. Ако
неко једном промени ту формулацију, тест падне.

Пиротско ћилимарство је 18. јуна 2012. уписано у **Национални регистар
нематеријалног културног наслеђа Србије** (редни број 6). То није исто што и
упис на UNESCO репрезентативну листу — регистар се води у оквиру UNESCO
конвенције из 2003.

## Правила заната, записана као кôд

`cilim/pravila.py` нема ниједан неурон. Три ствари долазе право из заната:

| правило | одакле | где је у коду |
|---|---|---|
| **Пет појасева** — ресе, спољашњи ћенар, бордура, унутрашњи ћенар, поље | грађа ћилима | `pojasevi()` |
| **Симетрија** — шара се гради огледањем и понављањем | сви извори о шарама | `ogledaj()` |
| **Два лица** — клечање даје оба лица потпуно иста, па нема пловећих нити | по томе се пиротски разликује од осталих балканских | `proveri()`, `ujednaci_poteze()` |

Треће правило је оно које дифузиони модел најчешће крши: он воли косу линију и
меки прелаз, а разбој их не уме. Провера мери **дужине потеза у реду** — потез
је оно што ткаља отка у једном маху — и пријави колико их је краће од прага.

> Правило се мери на **мрежи картона**, не на пикселима. Ћелија картона је оно
> што се тка; ситан детаљ лако прође пиксел-проверу а падне на разбоју.

## Хардвер

- NVIDIA Jetson Orin Nano Developer Kit (8 GB), активни хладњак, напајање 19 V
  (уз JetPack 6.2 иста плоча ради у „Super“ режиму — до 67 TOPS)
- Logitech C922 Pro Stream изнад радне површине
- NVMe SSD (дифузиони модел је велик)
- Екран на додир — на њему се црта скица
- Равномерно бочно осветљење

Ради и на обичном рачунару. **Без иједног модела ради у режиму `pravila`** (доле).

## Инсталација

```bash
git clone https://github.com/tspirot/edgeai.git
cd edgeai/projekti/pirotski-cilim
python -m venv .venv
source .venv/bin/activate        # Windows: .venv\Scripts\activate
pip install -e .                 # језгро: правила, картон, каталог, тестови

pip install -e ".[kamera]"       # камера (OpenCV)
pip install -e ".[klasifikator]" # torch + timm (ViT препознавање шара)
pip install -e ".[difuzija]"     # diffusers + torch (SD 1.5 + ControlNet)
```

Модели (једном, уз интернет):

```bash
cilim download-model
```

## Покретање

```bash
cilim motivi --sve                 # каталог шара: шта уређај зна и шта је потврђено
cilim procitaj --image cilim.jpg   # која је ово шара и шта значи
cilim smisli --skica skica.png --motiv kornjaca -o izlaz/
cilim karton gotova-sara.png       # готова слика → картон за ткање
cilim devices
```

Без хардвера и без иједног преузетог модела:

```bash
cilim procitaj --klasifikator dummy --image bilo-sta.jpg
cilim smisli --generator pravila --motiv sofra --seed 7 -o izlaz/
```

Излаз у `izlaz/`: `sara.png` (како изгледа), `karton.csv` (индекси боја по
ћелији) и `karton.png` (мрежа за штампу, да се броји прстом).

## Како ради

```
камера (C922) ──► шара на ћилиму ──► ViT класификатор ──► име и значење
екран на додир ──► скица ученика
                        │
        ControlNet ◄────┤  скица као ограничење
                        ▼
             SD 1.5 + LoRA (int8/TensorRT)  ──► слика са меким прелазима
                        │
        ПРАВИЛА ЗАНАТА ─┤  палета → потези → симетрија
                        ▼
                    картон за ткање ──► ткаља каже да ли је изводљиво
                        │
                   исткан комад ──► назад у скуп података
```

### Модули (заменљиви)

| корак | подразумевано | алтернатива |
|---|---|---|
| класификатор | `vit` (дообучен на школском скупу) | `dummy` (детерминистичан, без модела) |
| генератор | `difuzija` (SD 1.5 + ControlNet) | `pravila` (процедурално, без модела) |

Режим `pravila` није само резерва. Он је **мерило**: ако дифузиони модел не даје
шару бољу од чисто процедуралне, не вреди својих петнаест вати.

## Каталог шара

`cilim/motivi.yaml` — почетни списак од шеснаест назива, **ниједан још није
потврдила радионица**. Свака одредница носи извор назива, а програм уз
непотврђено значење увек исписује ограду:

```
корњача: Дуг живот, постојаност и благостање. Стоји и на грбу града Пирота.
[НЕПОТВРЂЕНО — назив преузет из: nkns, vikipedija, literatura; проверити у радионици]
```

Посао ученика: проћи кроз списак са школском радионицом, исправити значења,
допунити (званични каталог броји преко стотину шара и орнамената) и
`potvrdila_radionica` пребацити на `true` уз име особе која је потврдила.

## Обазриво

- **Модел лако нацрта шару коју је немогуће исткати.** Картон увек проверава
  ткаља пре него што се прогласи употребљивим. Прва мера успеха није лепота
  слике него колико картона прође ту проверу.
- **Каталог није поуздан док га радионица не потврди.** Значења су преузета из
  литературе.
- **Палета боја је приближна.** Тачне вредности се добијају мерењем на стварним
  клубадима, под истим светлом.
