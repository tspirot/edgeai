# Скуп података и обука

Ни тежине класификатора ни LoRA не долазе уз пакет и не преузимају се. Оне
настају у школској радионици — то је, уз картон за ткање, оно што овај пројекат
раздваја од вежбе.

## 1. Снимање

Циљ: неколико стотина исечака по шари.

- Камера право надоле, ћилим раван, **светло са обе стране кроз дифузор**.
  Ако осветљење није равномерно, сенка између нити улази у слику као да је део
  шаре — иста замка као код „Контроле квалитета“.
- Сваку шару сними са више ћилима, не само са једног. Модел иначе научи ћилим,
  не шару.
- Сними и разбој у раду: полуготова шара је други изглед исте ствари.
- Забележи **чији је ћилим** и да ли је власник дао сагласност. То иде у
  евиденцију скупа, не у главу.

## 2. Означавање

Label Studio, исти поступак као код „Знаковне азбуке“.

- Класе су `id` из `cilim/motivi.yaml` — не измишљај нове називе у Label
  Studio-у него прво допуни каталог.
- Означава се исечак у ком је шара цела. Пола шаре је шум.
- Спорне случајеве **не погађај** — остави их за ткаљу.

## 3. Каталог пре обуке

Обука има смисла тек кад је каталог проверен:

```bash
cilim motivi --sve
```

Прођи кроз списак са неким ко тка. За сваку одредницу: тачан назив, тачно
значење, у ком делу ћилима стоји. Тек тада `potvrdila_radionica: true`, уз име
особе и датум у коментару.

> Редослед класа у тежинама мора да прати каталог. Ако се каталог промени после
> обуке, `VitKlasifikator` то примети и одбије да ради — боље грешка него модел
> који говори туђа имена.

## 4. Обука класификатора

Мали ViT (`vit_small_patch16_224`), дообучавање на школском скупу. Тренинг на
рачунару са GPU, не на Jetson-у. Излаз:

```python
torch.save({"model": model.state_dict(), "klase": list(katalog.imena)},
           "models/klasifikator/sare.pt")
```

Поље `klase` није украс — по њему `cilim` проверава да се модел и каталог слажу.

## 5. LoRA за дифузиони модел

LoRA се обучава на истим сликама, са описом који садржи назив шаре. Без ње SD
1.5 даје уопштен тепих, не пиротску шару — програм на то и упозори у логу.

## 6. Мерење

Оно што иде на Demo Day нису слике него бројке:

| мера | како |
|---|---|
| тачност класификатора | подела скупа по ћилимима, не по исечцима — иначе модел препозна ћилим |
| удео изводљивих предлога | `cilim smisli` за N семена, преброј `izvodljivo()` |
| **колико картона је ткаља прогласила изводљивим** | руком, и то је најважнија бројка |
| кашњење по кораку | `cilim smisli -v`, уз `tegrastats` у другом терминалу |

Последња мера је она права. Модел који даје лепе слике а неизводљиве картоне
није решио задатак.
