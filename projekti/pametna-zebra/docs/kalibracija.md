# Калибрација „Паметне зебре"

Две ствари се подешавају једном, по постављању камере: **зоне** (где је прелаз,
где коловоз) и **размера** (колико метара је један пиксел).

## 1. Зоне — `zebra calibrate`

```bash
zebra calibrate --source 0 -o zones.json
```

- Отвори се један кадар са камере.
- Леви клик = теме полигона. Прво означи **пешачки прелаз** (4+ тачке), па `ENTER`.
- Онда означи **коловоз** (део пута који камера види), па `ENTER`.
- `Z` брише последњу тачку, `ESC` прекида.
- Сними се `zones.json`; `zebra run` га сам учита.

Савети:
- Прелаз означи мало шире од белих линија — ту пешак „чека" и креће.
- Коловоз означи само траку којом иду возила ка прелазу, не цео кадар.

## 2. Размера — `meters_per_pixel`

Треба за рачунање брзине и времена до судара (TTC).

1. Измери на лицу места једно познато растојање — нпр. ширину пешачког прелаза
   (обично 3 m) или размак две беле линије.
2. У сачуваном кадру избрОј колико пиксела је то растојање.
3. `meters_per_pixel = метри / пиксели`. Пример: 3 m преко 60 px → `0.05`.
4. Упиши у `config.yaml`:

```yaml
safety:
  meters_per_pixel: 0.05
```

Ако камера гледа укосо, размера није иста на врху и дну кадра — за школски
пројекат је довољна једна просечна вредност око зоне прелаза. Прецизније би
тражило хомографију (могући наставак пројекта).

## 3. Праг упозорења

```yaml
safety:
  ttc_seconds: 3.0        # упозори кад је до судара мање од 3 s
  conflict_radius_m: 2.0  # ближе од 2 m се сматра сударом
  hold_seconds: 2.0       # колико упозорење остаје после окидача
```

Тестирај у условима демоа — ако упозорење касни, повећај `ttc_seconds`;
ако се пали без разлога, смањи га или сузи зоне.
