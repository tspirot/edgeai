# Постављање фотозамке на терену

## Пре изласка

1. `cuvar run --source 0 --classify onnx` у учионици — провери да класификатор
   ради и да окидач не „лаже" на пролазне сенке.
2. `cuvar power --triggers-per-hour 4` — процени колико дана батерија држи за
   очекивани ритам догађаја на локацији.
3. Синхронизуј сат Pi-ја (`sudo timedatectl set-time ...`) — временске ознаке
   у `snimci/*.json` морају бити тачне.
4. Напуни батерију, стави свежу microSD (или очисти `snimci/`).
5. Укључи autostart сервис (`systemd`) да се `cuvar run` подигне сам.

## На локацији

- Камера на 40–60 cm висине, благо надоле, ка стази/појилу.
- Избегни директно сунце у објективу (лажни окидачи) и високу траву испред.
- BME688 у сенци кућишта, са отвором за ваздух — не на директном сунцу.
- Забележи GPS тачку и датум постављања.

## Повратак

```bash
cuvar gallery                 # преглед: које врсте, колико пута
```

Пренеси `snimci/` на рачунар. `.json` фајлови су спремни за унос у табелу
(врста, време, температура, влажност, AQI) — то је податак за јавну презентацију.

## Калибрација AQI (BME688)

Отпорност гаса зависи од саме јединице и старости сензора. У чистом ваздуху
(нпр. напољу, ујутру) очитај `gas_ohm` неколико минута и ту вредност упиши као
`baseline_ohm` — AQI се рачуна као пад у односу на ту базну линију.
