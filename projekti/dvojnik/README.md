## Зашто окретни сто

Класично 3D скенирање мора само да погоди где је камера била у сваком тренутку
(визуелна одометрија). Тај корак губи траг на једнобојном предмету, при брзом
покрету и на сјајној површини — и ту већина школских покушаја пропадне.

Овде корачни мотор окреће сто за **наређен** угао, па се положај не процењује
него зна. Исти принцип као сигурносни слој код „Ђака за воланом“: не процењуј
оно што можеш да измериш.

## Две границе методе — обе мерене, не претпостављене

Реконструкција је **визуелни омотач**: најмање тело које баца исте сенке као
оригинал. Из тога следе две ствари које нису квар него математика, и свака има
свој тест:

| граница | шта значи | тест |
|---|---|---|
| **Удубљења остају пуна** | Унутрашњост шоље се са стране не види као рупа, па се не може ни одрезати. Шоља испадне пун ваљак. | `test_karving.py::test_solja_ostaje_puna` |
| **Висина се прецењује** | Сви кадрови су са исте висине камере. Воксел изнад предмета, са супротне стране, пада у исти део слике као његов врх. | `test_karving.py::test_visina_se_precenjuje_jer_su_svi_uglovi_sa_iste_visine` |

Водоравне мере су тесне — сто их обиђе у круг. Ко хоће тесну и висину, снима
два круга са две висине камере.

## Скенер нема осећај за величину

Из слика се добија облик, не мере. Док се не унесе једна права дужина, модел
може бити и напрстак и буре:

```bash
dvojnik slozi snimak/ --visina-mm 84.5     # измерено шублером
```

То је најбоља лекција пројекта: једна измерена бројка вреди више од сто кадрова.

## Хардвер

- NVIDIA Jetson Orin Nano Developer Kit (8 GB), активни хладњак, напајање 19 V
- Logitech C922 Pro Stream на **непомичном** сталку
- Окретни сто: корачни мотор 28BYJ-48 + ULN2003 драјвер, плоча 3D штампана
- Матирана позадина у контрастној боји
- Дифузно осветљење са обе стране, непроменљиво
- Шублер
- 3D штампач који школа већ има

Ради и на обичном рачунару — **без камере и стола цео ланац ради у симулацији**.

## Инсталација

```bash
git clone https://github.com/tspirot/edgeai.git
cd edgeai/projekti/dvojnik
python -m venv .venv
source .venv/bin/activate        # Windows: .venv\Scripts\activate
pip install -e .                 # језгро: геометрија, резбарење, мрежа, STL

pip install -e ".[kamera]"       # камера (OpenCV)
pip install -e ".[sto]"          # GPIO за корачни мотор
pip install -e ".[glatko]"       # scikit-image → marching cubes уместо коцкица
```

## Покретање

```bash
# без хардвера — синтетички предмет кроз цео ланац
dvojnik sim --telo kugla --mera 60 -o izlaz/
dvojnik sim --telo solja --mera 60 -o izlaz/    # погледај шта се деси удубљењу

# са хардвером
dvojnik devices
dvojnik sto --stepeni 360                       # проба мотора
dvojnik snimi --kadrova 120 -o snimak/
dvojnik slozi snimak/ --visina-mm 84.5 -o izlaz/
```

Излаз: `izlaz/model.stl`, у милиметрима, спреман за резач.

## Како ради

```
окретни сто ──► угао сваког кадра је ПОЗНАТ (корачни мотор)
камера ──► кадар
празна позадина ──► одузимање ──► силуета (маска)
                                     │
   коцка воксела ◄── свака силуета одсече све што пада ван ње
                                     │
                      блоковска мрежа (или marching cubes)
                                     │
                    ×  измерена висина  ──► размера
                                     ▼
                                 model.stl ──► штампач
```

Резбарење је очигледно паралелан посао — сваки воксел независно. Писано је у
NumPy-ју да се види шта се ради; пребацивање на CUDA језгра је у
`docs/na-jetsonu.md`.

## Подешавање кад нешто не ваља

| симптом | узрок | шта урадити |
|---|---|---|
| „силуета је празна“ | предмет се не разликује од позадине | спусти `silueta.prag`, промени позадину |
| после резбарења нема ништа | предмет излази из кадра, или радни простор не поклапа сто | одмакни камеру, провери `zapremina.precnik` |
| модел изједен изнутра | рупе у маски | подигни `silueta.zatvaranje` |
| ивице отопљене | сенка улази у силуету | дифузно светло са обе стране, матирана позадина |
| модел се тресе између кадрова | аутофокус или аутоекспозиција раде | закључај их на камери |

## Тестови

```bash
pip install -e ".[dev]"
pytest
```

79 тестова, без камере и стола. Тела су задата формулом, па се тачна димензија
**зна** — реконструкција се пореди са бројем, не гледа. Покривено: пројективна
геометрија, морфологија силуета, резбарење (кугла, коцка, ваљак, шоља), обе
границе методе, блоковска мрежа и бинарни STL, размера, учитавање снимка.
