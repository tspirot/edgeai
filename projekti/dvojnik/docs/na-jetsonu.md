# На Jetson-у: зашто је GPU брз, без иједног неурона

Резбарење воксела је најчистији пример паралелног посла у целом програму. За
сваки кадар се сваки воксел независно пројектује у слику и провери да ли пада у
силуету. Са мрежом 160³ и 120 кадрова то је **500 милиона пројекција**, а
ниједна не зависи од друге.

Управо за то су CUDA језгра направљена — и то без иједне неуронске мреже. Овде
ученици виде разлику између „GPU = вештачка интелигенција“ (нетачно) и
„GPU = много истих рачуна одједном“ (тачно).

## Мерење пре оптимизације

```bash
dvojnik sim --telo kugla --kadrova 120 -v      # NumPy, на процесору
tegrastats                                      # у другом терминалу
```

Забележи време. Без тог броја оптимизација нема смисла.

## Пребацивање на GPU

Језгро је у `karving.py`, у петљи по кадровима. Израз је већ векторизован, па
се мења само библиотека — `cupy` ради као замена за `numpy`:

```python
import cupy as cp

tacke_gpu = cp.asarray(tacke)
zauzeto = cp.ones(tacke_gpu.shape[0], dtype=cp.bool_)
for maska, ugao in zip(siluete, uglovi):
    m = cp.asarray(maska)
    Pw = tacke_gpu @ cp.asarray(rotacija_z(ugao).T)
    # …исти рачун као у NumPy верзији…
    zauzeto &= unutra
zauzeto = cp.asnumpy(zauzeto)
```

Пази на две ствари:

1. **Пренос кошта.** Пошаљи тачке на GPU једном, пре петље, не у сваком кораку.
   Ко у петљи ради `cp.asarray(tacke)`, добије спорије него на процесору.
2. **Меморија.** 160³ воксела × 3 координате × 8 бајтова ≈ 100 MB. Прође, али
   у `float32` је упола мање и довољно тачно за милиметарску мрежу.

## Систем

```bash
sudo nvpmodel -m 0        # MAX-N режим
sudo jetson_clocks         # закуцај фреквенције
```

Резбарење оптерети GPU до краја, па без активног хлађења плоча успори усред посла.

## Шта мерити за Demo Day

| мера | како |
|---|---|
| време реконструкције на процесору | `dvojnik sim --kadrova 120 -v` |
| исто на GPU | иста команда, `cupy` верзија |
| убрзање | однос та два броја — то је прича |
| потрошња | `tegrastats` током рада |
| тачност | одштампану копију на шублер, упореди са оригиналом |

Последња мера је најважнија. Убрзање је занимљиво, али двојник који је за пет
милиметара промашен није двојник.
