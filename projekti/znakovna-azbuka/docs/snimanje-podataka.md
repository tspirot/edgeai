# Снимање скупа података

## Правило: разноликост, не количина

30 добрих узорака по слову од **више ученика**, у **разним условима**, боље је
од 300 узорака једне руке у једном осветљењу.

Промени између узорака:
- ученик (величина шаке, начин држања)
- удаљеност од камере и угао руке
- осветљење (прозор, плафоњера, лампа)
- позадина

## Ток

```bash
znak record --label A -n 40      # SPACE = сними тренутни положај, Q = крај
znak record --label B -n 40
# ... сва слова која радите ...
znak train                        # podaci.csv → model.npz
znak run                          # провера уживо
```

`podaci.csv` садржи **сирове тачке** (не нормализоване), па се нормализација
може касније мењати без поновног снимања.

## Label Studio (опционо)

За веће скупове: снимите видео/слике, у Label Studio означите оквир шаке и слово,
извезите, па конвертујте у `podaci.csv` форматом `label,x0,y0,...,x20,y20`.
Тако анотацију ради више људи паралелно и има преглед квалитета.

## Провера квалитета

- `znak run` па показуј свако слово 3 s — колико пута погоди?
- Слова која се мешају → сними им још узорака, или их привремено избаци.
- Матрица забуне (који пар се меша) је добра тема за извештај на Demo Day-у.

## Слова са покретом

Ж, Ћ, Ђ, Љ, Њ и др. се у знаковној азбуци исписују покретом. Тренутни модел
гледа један кадар. Проширење: чувати низ од N кадрова и класификовати путању
(мали временски класификатор) — то је природан следећи корак пројекта.
