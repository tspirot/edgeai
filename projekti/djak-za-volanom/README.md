# Ђак за воланом

Аутономна вожња у размери 1:10. Камера и мали CNN држе траку; **RPLIDAR A1 је
независни сигурносни слој** који зауставља ауто пред препреком без обзира на то
шта модел предвиђа. Пројекат програма [Edge AI Пирот](https://edgeai.tsp.edu.rs).

Све ради на самом уређају (Raspberry Pi у аутомобилу), офлајн. Пар са пројектом
„Паметна зебра“ — тамо се прелаз посматра одозго, овде из аутомобила.

## Хардвер

- Waveshare PiRacer AI Kit (шасија 1:10, серво, ESC, PCA9685, INA219, OLED)
- Raspberry Pi 4 (4 GB) + активно хлађење
- Камера напред (Camera Module или USB, широки угао)
- Slamtec RPLIDAR A1 на USB
- 2× 18650 за вожњу (+ power bank за Pi по потреби)
- Bluetooth гејмпад за снимање података

Без хардвера ради у симулацији: `volan sim`.

## Инсталација

```bash
git clone https://github.com/tspirot/edgeai.git
cd edgeai/projekti/djak-za-volanom
python3 -m venv .venv
source .venv/bin/activate        # Windows: .venv\Scripts\activate
pip install -e .                 # језгро: симулација, тестови

pip install -e ".[kamera,lidar,pwm,gamepad]"   # на аутомобилу
pip install -e ".[train]"                       # на рачунару, за обуку
```

## Ток рада

```bash
volan sim                              # проба целог ланца без хардвера
volan check                            # камера, лидар, серво — раде ли

volan record --seconds 120             # 1) ручна вожња, снима data/<сесија>/
volan train data/ -o models/pilot.tflite   # 2) обука CNN-а (на рачунару)
volan drive                            # 3) аутономна вожња
# 4) погледај где излеће, сними још, врати се на корак 2
```

## Како ради

```
камера ──► препроцес 120×160 ──► CNN политика ──► угао волана (и гас)
                                                        │
RPLIDAR ──► најближа тачка у конусу испред ──► сигурносни арбитар
                                                        │
                                    праг + хистереза: препрека → гас на 0
                                                        │
                                    PCA9685 ──► серво (волан) + ESC (гас)
```

### Заменљиви модули

| корак | подразумевано | алтернативе |
|---|---|---|
| камера | `auto` (Picamera2 → OpenCV) | `dummy` (синтетичка трака) |
| политика | `tflite` (истрениран CNN) | `heuristic` (прати светлу траку), `dummy` |
| лидар | `auto` (RPLIDAR → dummy) | `dummy` (препрека на задатом mm) |
| актуатор | `auto` (PCA9685 → dummy) | `dummy` (бележи команде) |

## Зашто камера И лидар

Камерски модел је научен на стази какву је видео. На новом осветљењу или пред
препреком коју није срео — погреши. Зато одлуку о кочењу не доноси он, него
**засебан систем над лидаром: обичан праг са хистерезом**, који се може
објаснити, тестирати и не мења се тренингом. Критична функција не сме да зависи
од једног модела — то је основни принцип безбедних аутономних система.

## Безбедност при раду

- Почни са ниским `drive.max_throttle` (0.3–0.4). Подижи тек кад вожња буде поуздана.
- Стаза са благим кривинама, довољно широка, без препрека које лидар не види (стакло, танке ноге).
- Точкови у ваздуху при првом покретању `drive` — провери смер пре него што спустиш ауто.

## Тестови

```bash
pip install -e ".[dev]"
pytest
```

Покривају конфигурацију, рачун конуса лидара, сигурносни арбитар (праг + хистереза),
хеуристичку политику, снимање/читање скупа и цео ланац у симулацији.
