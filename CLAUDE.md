# Упутства за рад у овом репоу

Монорепо програма „Edge AI: Наука у петој брзини“ (Техничка школа Пирот).
`web/` сајт · `lms/primeri/` примери за Pi · `projekti/` 12 пројеката · `deploy/` деплој.

## Команде
* Сајт: `cd web && npm run dev` / `npm run build` (мора да прође пре комита).
* Пројекат: у његовом фолдеру `pip install -e ".[dev]" && pytest`.
* Примери за Pi: `source ~/primeri/env/bin/activate`, па `python …` из `lms/primeri/<фолдер>`.

## Конвенције
* Садржај сајта и документација: **ћирилица**. Имена фајлова, променљивих и slug-ова: латиница без дијакритика.
* Нова лекција/пример/пројекат иде у `web/src/data/` (`lms.js`, `lmsUvod.js`, `lmsKviz.js`, `projekti.js`, `uputstva.js`); користи постојеће блокове (`p`, `h`, `steps`, `code`, `shema`, `callout`). Скилови: `/novo-uputstvo`, `/novi-projekat`, `/edgeai-design-system`.
* Везе лекција ↔ примера иду у оба смера (`lekcija.primeri` и `primer.lekcije`); проверити пре комита.
* Тврдње у лекцијама се пишу по ономе што код стварно ради, ништа „по сећању“.

## Не радити
* Не уписивати тајне у git (види `SECURITY.md`); `deploy/.env` је само на серверу.
* Не додавати слике лица/гласове ученика; не додавати материјал трећих страна без записа у `CREDITS.md`.
* `git push` у `main` објављује сајт (webhook): пушовати само на изричит налог.
