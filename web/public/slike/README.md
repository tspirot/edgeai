# Медиј сајта (`web/public/slike/`)

Овде иду фотографије, снимци екрана и видео демонстрације. Кодиране SVG схеме
**не иду овде** — оне су React компоненте у `web/src/components/sheme/`.

## Зашто `public/`, а не `src/assets/`

README-ји пројеката се рендерују преко `marked` из сировог markdown-а
(`web/src/components/Readme.jsx`) и не пролазе кроз Vite-ово разрешавање путања.
Апсолутна путања `/slike/<slug>/ime.webp` ради и у JSX-у и у markdown-у.

## Именовање

```
slike/<slug-projekta>/hero.webp        насловна слика пројекта (16:9)
slike/<slug-projekta>/demo.mp4         видео демонстрација рада
slike/<slug-projekta>/demo.webp        постер кадар за тај видео
slike/<slug-projekta>/sklop-01.webp    фотографије склапања, редом
slike/uputstva/<slug>/korak-03.webp    кораци из упутства
slike/share/edgeai-share.png           заједничка картица за дељење (1200×630)
```

## Правила

- **Видео, не GIF.** `.mp4` је око десет пута мањи од GIF-а истог садржаја.
  `Figure` компонента сама препознаје наставак и рендерује `<video>`.
- **`alt` је обавезан.** У развојном режиму `Figure` испише упозорење ако недостаје.
- **Ширина највише 1600 px**, `.webp` квалитет ~80. Слике се не верзионишу хешом,
  па им `.htaccess` даје рок кеша од 30 дана (не `immutable`).
- **Тема.** Растер не прати светло/тамно. Ако слика мора да ради у обе теме,
  дај и `srcDark` варијанту или користи снимак на неутралној позадини.

## Употреба у садржају

```js
{ type: 'figure', src: '/slike/titlovi-uzivo/demo.mp4',
  poster: '/slike/titlovi-uzivo/demo.webp',
  alt: 'Титлови се исписују док говорник говори.',
  caption: 'Демонстрација на Raspberry Pi 5, снимак екрана пројекције.' }
```

Насловна слика пројекта се додаје као поље `slika:` у `web/src/data/projekti.js` —
тада се појављује и на картици пројекта и као слика при дељењу линка.
