# Промптови за илустрације

Ове слике не могу да настану из репоа — генеришу се спољним алатом и ручно
убацују у одговарајући подфолдер. Промптови су подешени према палети сајта да
илустрација не одудара од остатка.

## Заједнички део (додај сваком промпту)

```
Стил: технички редукован, равне површине, без сјаја и без 3D рендера.
Палета: дубока зелено-црна позадина #090E0C, ментол акценат #4ED8A3,
месингани детаљ #E5B842, светли текст #EDF5F0.
Однос страна 16:9, 1600×900. Без текста и без логотипа на слици.
Без људских лица. Изглед школске лабораторије, не корпоративног студија.
```

> Слика се не мења са темом сајта. Зато позадину држи тамну и неутралну —
> у светлој теми стоји унутар оквира са ивицом, што и даље изгледа намерно.

## Где иду фајлови

```
web/public/slike/<slug>/hero.webp
```

па се у `web/src/data/projekti.js` том пројекту дода:

```js
slika: '/slike/<slug>/hero.webp',
```

Тиме слика улази и на картицу пројекта и у преглед при дељењу линка.
Насловна слика **не замењује схеме** — оне носе техничку информацију,
илустрација носи утисак.
