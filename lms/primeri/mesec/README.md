# Месец у длану — тродимензионално лебдеће светло

![ниво: средње](https://img.shields.io/badge/%D0%BD%D0%B8%D0%B2%D0%BE-%D1%81%D1%80%D0%B5%D0%B4%D1%9A%D0%B5-2f6fed) ![хардвер: Camera Module 3](https://img.shields.io/badge/%D1%85%D0%B0%D1%80%D0%B4%D0%B2%D0%B5%D1%80-Camera_Module_3-c51a4a) ![Python: 3.9+](https://img.shields.io/badge/Python-3.9%2B-3776ab)

Тродимензионални реално осветљени Месец са кратерима лебди непосредно изнад отвореног длана, ротира се и верно осветљава твоје лице и собу према физичком моделу опадања јачине светлости.

![Месец у длану — 3D лебдеће светло](/slike/primeri/mesec.jpg)

## Покретање

```bash
cd ~/primeri/mesec
python mesec.py
```

## Контроле

- **Покрет отвореног длана:** Месец глатко лебди тачно изнад средишта шаке.
- **`[m]`:** Промени тему боје месеца (Златна лунарна → Сајбер плава → Крвави месец → Емералд зелена).
- **`[+]` / `[-]`:** Повећај или смањи пречник Месеца.
- **`[q]` или `[ESC]`:** Излаз из апликације.

## Како ради

```text
       Кадар са камере (Picamera2)
                    │
                    ▼
          MediaPipe Hands (21 тачка)
                    │
                    ▼
     Тежиште длана (Landmarks 0, 5, 9, 17)
                    │
                    ▼
   Експоненцијално глачање (EMA филтер):
   pos = 0.65 · pos_staro + 0.35 · pos_novo
                    │
   ┌────────────────┴────────────────┐
   ▼                                 ▼
3D Текстура Месеца са кратерима  Радијални кернел физичког светла
(исцртавање и ротација кугле)    I = 1 / (1 + (d / 60)²)
   │                                 │
   └────────────────┬────────────────┘
                    ▼
       Адитивно блендовање на кадар:
       cv2.addWeighted(kadar, 1.0, svetlo, snaga, 0)
```

1. **Експоненцијално глачање позиције (EMA филтер):**
   - Да виртуелни Месец не би дрхтао услед малог шума камере, примењује се филтер експоненцијалног помичног просека: $P_t = 0.65 \cdot P_{t-1} + 0.35 \cdot M_t$, где је $M_t$ сирово мерење са модела.

2. **Физички модел радијалног опадања светлости (Inverse-square falloff):**
   - Светлост у природи опада са квадратом растојања: $I \propto \frac{1}{r^2}$.
   - Скрипта унапред прави 2D кернел радијуса 240 пиксела помоћу NumPy координата: `light_kernel = 1.0 / (1.0 + (dist / 60.0)**2)`. Тај кернел додаје меко, природно амбијентално светло које осветљава лице и позадину око руке.

## Додатак: Хардверска надградња са сетом „37 у 1” 🌕🔌

1. **RGB LED (KY-016) на GPIO 22, 27, 23:**
   - Права физичка лампа на столу светли усклађено са одабраном лунарном темом на тастер `[m]`.
2. **Фотоотпорник (KY-018) преко ADC-а:**
   - Мери стварну таму у просторији: што је соба мрачнија, виртуелни Месец на екрану сија интензивније!
