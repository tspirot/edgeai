# КВО ТЕ — Пиротски AI Мозак

Интерактивна локална AI машина за Raspberry Pi 5 која одговара на питања на аутентичном **пиротском (торлачком) дијалекту**, даје животне савете о штедњи, пегланој кобасици, качкаваљу, времену, прича вицеве и говори наглас преко звучника.

100% локално на уређају, ради потпуно офлајн.

![КВО ТЕ — Пиротски AI мозак](/slike/primeri/kvo-te.jpg)

## 🪟 Како покренути на Windows-у

Најлакши начин је двоструки клик на **`pokreni.bat`** или из командне линије:

- **💬 ПиротGPT — ChatGPT интерфејс за Пироћанци (препоручено):**
  Отворите: **`http://localhost:8080/chat`**
  - Разговор са моделом у форми правог ChatGPT-а са историјом сесија
  - 3 персоне: **Бајица Станко** (Тврди штедиша), **Чика Добри** (Мераклија & боем), **Проф. Златковић** (САНУ Зналац)
  - Стримовање текста у реалном времену
  - Ауто-говор сваког одговора на пиротском (Web Speech + SAPI)
  - Препоручене стартер картице и мулти-турн меморија

- **📺 Кво Те — Интерактивни Киоск интерфејс:**
  Отворите: **`http://localhost:8080`**
  - Анимирани Пироћанец са гласовним таласима, брзи тастери 1-6, САНУ речник са 2.726 одредница.

- **Pygame графички прозор на екрану:**
  ```cmd
  python kvo_te.py --windowed
  ```

- **Брзо у конзоли (CLI режим):**
  ```cmd
  python kvo_te.py --cli
  ```

## 🚀 Како покренути на Raspberry Pi 5

### 1. Активација виртуелног окружења
```bash
source ~/primeri/env/bin/activate
# или: source ~/venv/bin/activate
```

### 2. Улазак у фолдер пројекта
```bash
cd ~/projekti/kvo-te
# или: cd ~/primeri/kvo-te
```

### 3. Покретање

- **Веб интерфејс:**
  ```bash
  python web_kvo_te.py
  ```

- **Графички приказ преко целог екрана (HDMI TV / монитор):**
  ```bash
  python kvo_te.py
  ```

- **У прозору (Windowed):**
  ```bash
  python kvo_te.py --windowed
  ```

- **Брзо у терминалу (CLI режим, одлично за SSH):**
  ```bash
  python kvo_te.py --cli
  ```

- **Без звука (тихи режим):**
  ```bash
  python kvo_te.py --bez-zvuka
  ```

## 🎮 Контроле у апликацији

| Тастер | Функција |
|---|---|
| **Тастатура + ENTER** | Упиши било које питање и притисни `ENTER` |
| **`[1]`** | Брзо питање: Паре и штедња |
| **`[2]`** | Брзо питање: Јело и пиће (пеглана кобасица, качкаваљ) |
| **`[3]`** | Брзо питање: Кво те мучи? |
| **`[4]`** | Брзо питање: Време и нишавац |
| **`[5]`** | Брзо питање: Љубав и брак |
| **`[6]`** | Брзо питање: Пиротски виц |
| **`[R]`** | Случајна реч и објашњење из пиротског речника |
| **`[M]`** | Укључи / искључи глас (Mute/Unmute) |
| **`[F]`** | Пребаци цео екран / прозор (Fullscreen toggle) |
| **`[C]`** | Очисти екран |
| **`[ESC]`** или **`[Q]`** | Излаз из програма |

## 📚 Научни модел пиротског говора (САНУ)

У фолдеру се налази и научни модел изграђен директно из `recnik.pdf`
(*Драгољуб Златковић, "Друга допуна Речнику пиротског говора", САНУ 2020.*):

- **`pirotski_model.json`**: 2.726 аутентичних одредница са врстом речи, књижевним значењем и примерима из села (Суково, Војнеговац, Крупац, Пирот, Петровац...).
- **`izgradi_model.py`**: Аутоматска скрипта која извлачи текст из `recnik.pdf` и поново гради модел.
- **`model_pirotskog_govora.py`**: Програмски интерфејс (API) за претрагу по пиротским речима, српским појмовима и насумичним примерима.

Питања попут *"шта значи абьр"*, *"кво значи аљав"* или *"како се каже невеста"* одмах дају тачан одговор и пример из зборника САНУ!
