Свака дигитална слика у рачунарском виду је обичан вишедимензионални низ целих бројева. Овај пример прави дигитални кадар од нуле без камере, анализира облик низа, сече регионе од интереса (ROI), прави маске и мења пикселе помоћу векторизованих NumPy операција.

## Како ради

```text
       NumPy 3D Array: shape (480, 640, 3)
       ┌────────────────────────────────────────────────────────┐  ▲
       │ [0, 0]                ...             [0, 639]         │  │
       │                                                        │  │ Visina (Y)
       │           kadar[100:200, 300:500] (Сечење ROI)         │  │ 480 redova
       │           ┌──────────────────────┐                     │  │
       │           │ Наранџасти пиксели   │                     │  │
       │           └──────────────────────┘                     │  │
       │                                                        │  ▼
       │ [479, 0]              ...             [479, 639]       │
       └────────────────────────────────────────────────────────┘
       ◄────────────────── Širina (X) 640 kolona ───────────────►
       Канали (Depth): 0 = Plava (B), 1 = Zelena (G), 2 = Crvena (R)
```

1. **Облик низа и координате:**
   - Кадар се иницијализује као `np.zeros((480, 640, 3), dtype=np.uint8)`.
   - Редослед димензија је `(висина, ширина, канали)`, односно `[red, kolona, kanal]`. Први индекс је $Y$, други је $X$.
   - Тип података `uint8` чува вредности од 0 до 255 (један бајт по пикселу по каналу).

2. **BGR распоред боја у OpenCV/NumPy свету:**
   - Канал 0 је плава (B), канал 1 зелена (G), а канал 2 црвена (R). Наранџаста боја је зато `(0, 165, 255)`.

3. **Брзо сечење и маскирање без petlji (Vectorization):**
   - Уместо спорих `for` петљи, сечење области ради се исечцима: `kadar[100:200, 300:500]`.
   - Логичко маскирање `maska = kadar[:, :, 2] > 128` ствара 2D логичку маску у микросекундама.
   - Замена пиксела са `np.where(maska_3d, siva, kadar)` омогућава тренутну промену хиљада пиксела без губитка FPS-а.

## Вежба за ученике

1. Промени димензије кадра на Full HD `(1080, 1920, 3)` и измери утрошак RAM меморије помоћу `kadar.nbytes / 1024 / 1024` MB.
2. Направи плави правоугаоник димензија 100x100 тачно у центру кадра.
3. Израчунај просечну вредност зеленог канала помоћу `kadar[:, :, 1].mean()`.
