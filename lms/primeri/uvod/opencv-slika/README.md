## Како ради

```text
               Учитавање logo.png (BGR слика)
                             │
     ┌───────────────────────┼───────────────────────┐
     ▼                       ▼                       ▼
cv2.rectangle / circle    cv2.cvtColor(GRAY)      cv2.cvtColor(HSV)
Линије и текст            Један канал интензитета Нијанса, засићење, сјај
     │                       │                       │
     └───────────────────────┼───────────────────────┘
                             ▼
               Хоризонтално спајање (np.hstack)
              ┌─────────┬─────────┬─────────┐
              │ BGR     │ Сива    │ HSV     │
              └─────────┴─────────┴─────────┘
```

1. **Цртање геометрије преко слике:**
   - `cv2.rectangle(img, (x1, y1), (x2, y2), boja_bgr, debljina)`
   - `cv2.circle(img, (centar_x, centar_y), r, boja_bgr, debljina)`
   - Вредност `debljina = -1` испуњава цео облик.

2. **Зашто користимо просторе боја?**
   - **BGR:** Природан излаз за сензор камере и мониторе.
   - **Сиви ниво (Grayscale):** Смањује количину података за 3 пута (са 3 канала на 1 канал) и уклања утицај боје за алгоритме детекције ивица (Sobel, Canny).
   - **HSV (Нијанса, Засићење, Вредност):** Нијанса (H) је независна од јачине светла у соби, па је кључна за праћење обојених објеката без обзира на сенке.

## Вежба за ученике

1. Замени боју круга у центру у јарко жуту `(0, 255, 255)`.
2. Нацртај сопствено име у доњем левом углу слике користећи `cv2.putText`.
3. Издвој само H (Hue) канал из HSV слике и прикажи га посебно помоћу `cv2.imshow("Hue", hsv[:, :, 0])`.
