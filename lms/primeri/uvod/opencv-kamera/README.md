# OpenCV: главна петља са камером, Flip и FPS

![ниво: основно](https://img.shields.io/badge/%D0%BD%D0%B8%D0%B2%D0%BE-%D0%BE%D1%81%D0%BD%D0%BE%D0%B2%D0%BD%D0%BE-2f6fed) ![хардвер: Camera Module 3](https://img.shields.io/badge/%D1%85%D0%B0%D1%80%D0%B4%D0%B2%D0%B5%D1%80-Camera_Module_3-c51a4a) ![Python: 3.9+](https://img.shields.io/badge/Python-3.9%2B-3776ab)

Најмања функционална апликација за рачунарски вид у реалном времену: узима кадар са камере, окреће га хоризонтално као огледало, мери брзину у кадровима по секунди (FPS) и исписује преко слике.

![OpenCV: петља са камером уживо](/slike/primeri/opencv-kamera.jpg)

## Покретање

```bash
cd ~/primeri/uvod
python opencv_kamera.py
```

## Контроле

- **`[q]` или `[ESC]`:** Излаз из петље и гашење камере.

---

## Како ради

```text
       ┌────────────────────────────────────────────────────────┐
       │                 Иницијализација камере                 │
       │       (Picamera2 на Pi 5 или cv2.VideoCapture(0))       │
       └────────────────────────────┬────────────────────────────┘
                                    │
                                    ▼
                        ┌───────────────────────┐
                        │  Бесконачна while:    │
                        │                       │
                        │  1. Ухвати кадар      │
                        │  2. cv2.flip(kadar, 1)│ ◄─── Окретање као огледало
                        │  3. Израчунај FPS     │
                        │  4. cv2.putText(FPS)  │
                        │  5. cv2.imshow()      │
                        │  6. cv2.waitKey(1)    │
                        └───────────┬───────────┘
                                    │ [q] или [ESC]
                                    ▼
                        Ослобађање камере и излаз
```

1. **Адаптивни улаз за различит хардвер:**
   - На Raspberry Pi плочи код аутоматски користи хардверски убрзан `Picamera2` интерфејс за Camera Module 3.
   - На лаптопу код аутоматски прелази на `cv2.VideoCapture(0)` за обичну USB веб камеру.

2. **Зашто радимо хоризонтални Flip?**
   - Људски мозак очекује да покрет десне руке види на десној страни екрана (као у правом огледалу). `cv2.flip(kadar, 1)` преокреће колоне слике ($X$ осу).

3. **Тачно рачунање фреквенције кадрова (FPS):**
   - Мерењем разлике времена `time.time() - prethodno` добијамо период једног кадра $\Delta t$. FPS је реципрочна вредност: $\text{FPS} = \frac{1}{\Delta t}$.
