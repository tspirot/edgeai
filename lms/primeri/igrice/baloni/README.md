Прва рачунарска игра за децу и предшколце заснована на вештачкој интелигенцији и праћењу вида: шарени мехурићи лебде са дна ка врху екрана, а деца их пуцају једноставним додиром прстију у ваздуху уз пратећи звук и конфете.

![Чаробни мехурићи — пуцкање балона уживо](/slike/primeri/baloni.jpg)

## Покретање

```bash
cd ~/primeri/igrice/baloni
python baloni.py
```
*(или изабери игру [1] у главном менију: `python ~/primeri/igrice/pokretac_igrice.py`)*

## Контроле

- **Додир шаком или прстићима:** Додирни балон на екрану било којим прстом (палац, кажипрст, средњи прст) да пукне.
- **`[r]`:** Ресетуј игру и очисти балоне на екрану (Reset).
- **`[m]`:** Укључи / искључи звук пуцања (Mute).
- **`[q]` или `[ESC]`:** Повратак у главни мени.

## Како ради

```text
  Кадар са камере (Picamera2 RGB888)
               │
               ▼
   MediaPipe Hands (AI Детекција)
               │
               ▼
  Тачке додира: [4, 8, 12] (палац, кажипрст, средњи прст)
               │
               ▼
 ┌────────────────────────────────────────────────────────┐
 │        Провера геометријског судара са сваким балоном  │
 │          math.hypot(bx - px, by - py) < (r + 12)       │
 └─────────────────────────┬──────────────────────────────┘
                           │
             ┌─────────────┴─────────────┐
             ▼                           ▼
        НЕМА СУДАРА                   СУДАР!
   (балон лебди навише уз        ├── `b.is_popped = True`
    синусоидно таласање)         ├── Proceduralni audio pop (NumPy)
                                 ├── +10 поена у скору
                                 ├── Генерисање 20 честица конфета
                                 └── (Опционо) GPIO бљесак & зујалица
```

1. **Детекција вишеструких тачака додира:**
   - Модел `MediaPipe Hands` у реалном времену прати врхове најактивнијих прстију обе руке: Landmark 4 (палац), Landmark 8 (кажипрст) и Landmark 12 (средњи прст). Ово омогућава детету да користи целу шаку или обе руке истовремено.

2. **Геометрија судара и синусоидно лебдење:**
   - Балони крећу са дна кадра са насумичном брзином и полупречником $r \in [28, 42]\text{ px}$.
   - Сваки балон има своју фазу и фреквенцију хоризонталног њихања: $x = x_0 + \sin(\phi) \cdot A$, чиме се постиже природан утисак лелујања у ваздуху.
   - Судар са прстом се детектује брзом Еуклидском дистанцом: $\sqrt{(x_b - x_p)^2 + (y_b - y_p)^2} < (r + 12)$.

3. **Синтетизован звук без спољних фајлова:**
   - Игра не зависи од спољних WAV или MP3 датотека. Звук „пуцања” балона се генерише математички у NumPy низу експоненцијалним падом фреквенције од 750 Hz ка 180 Hz током 70 милисекунди:
   ```python
   t = np.linspace(0, 0.07, n, False)
   f = np.linspace(750, 180, n)
   env = np.exp(-12.0 * t / 0.07)
   wave = np.sin(2 * np.pi * f * t) * env * 0.35
   ```

4. **Асинхрона архитектура са Picamera2:**
   - Камера и вештачка интелигенција раде у независним позадинским нитима (`_cam_worker` и `_ai_worker`), што омогућава приказ у пуних 40+ FPS на Raspberry Pi 5 плочи без икаквог сецкања или кашњења.

## Додатак: Хардверска надградња са сетом „37 у 1” 🎈⚡

Игра се на лабораторијском столу лако проширује компонентама из сета 37 у 1:

1. **RGB LED (KY-016) на GPIO 22, 27, 23 — Светлосни ефекат поготка:**
   - Диода заблиста у боји балона који је управо пукао (црвена, плава, зелена, љубичаста или наранџаста), пружајући јасну визуелну повратну информацију детету.
2. **Зујалица (KY-006 пасивна или KY-012 активна) на GPIO 17 — Физички звучни клик:**
   - Окида кратак хардверски импулс од 20 ms при сваком пуцању балона.
3. **Тактилни тастер (KY-004) на GPIO 24 — Ресет тастер:**
   - Физичко дугме за ресетовање резултата и прављење нових балона.

```
                  Raspberry Pi 5 GPIO Pinout (Чаробни мехурићи)
                         ┌──────────────┐
       3.3V Power (Pin 1)│ ●  ● │(Pin 2)  5V Power
                         │ ●  ● │(Pin 6)  GND ────────────► [GND] Заједничка маса
   [S] Зујалица  (Pin 11)│ ●  ● │(Pin 12)
   [G] Зелена    (Pin 13)│ ●  ● │(Pin 14) GND ────────────► [GND] RGB LED (KY-016)
   [R] Црвена    (Pin 15)│ ●  ● │(Pin 16) GPIO 23 ───────► [B] Плава LED  (KY-016)
                         │ ●  ● │(Pin 18) GPIO 24 ───────► [S] Тастер Reset (KY-004)
                         └──────────────┘
```

### Пример проширења у Python-у

```python
from gpiozero import RGBLED, Buzzer, Button
import time

led = RGBLED(red=22, green=27, blue=23)
buzzer = Buzzer(17)
btn_reset = Button(24, pull_up=True)

# Ресет преко хардверског тастера
def reset_igre():
    global score, balloons
    score = 0
    balloons = [Balloon() for _ in range(6)]

btn_reset.when_pressed = reset_igre

# Када балон пукне:
def on_balloon_popped(palette):
    r, g, b = palette["body"]
    led.color = (r / 255.0, g / 255.0, b / 255.0)
    buzzer.on()
    time.sleep(0.03)
    buzzer.off()
    led.off()
```
