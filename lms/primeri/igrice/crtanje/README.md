# Чаробни штапић — цртање светлошћу у ваздуху

![ниво: основно](https://img.shields.io/badge/%D0%BD%D0%B8%D0%B2%D0%BE-%D0%BE%D1%81%D0%BD%D0%BE%D0%B2%D0%BD%D0%BE-2f6fed) ![хардвер: Camera Module 3](https://img.shields.io/badge/%D1%85%D0%B0%D1%80%D0%B4%D0%B2%D0%B5%D1%80-Camera_Module_3-c51a4a) ![Python: 3.9+](https://img.shields.io/badge/Python-3.9%2B-3776ab)

Кажипрст руке постаје чаробна четкица: MediaPipe прати тачке шаке у ваздуху, а програм црта глатки, светлећи дугин траг преко живе слике са камере уз пратећи звук чаробних искрица.

![Чаробни штапић — приказ рада уживо](/slike/primeri/crtanje.jpg)

## Покретање

```bash
cd ~/primeri/igrice/crtanje
python crtanje.py
```
*(или изабери игру [2] у главном менију: `python ~/primeri/igrice/pokretac_igrice.py`)*

## Контроле

- **Подигнут кажипрст:** Цртај чаробном светлуцавом линијом у ваздуху.
- **`[c]`:** Обриши цео цртеж (Clear canvas).
- **`[t]`:** Промени шаблон за попуњавање и вежбу (Празно → Звезда → Срце → Маца).
- **`[m]`:** Укључи / искључи звук искрица (Mute).
- **`[q]` или `[ESC]`:** Повратак у главни мени.

## Како ради

```text
  Кадар са камере (Picamera2)
             │
             ▼
  MediaPipe Hands (21 тачка шаке)
             │
  ┌──────────┴─────────────────────────┐
  ▼                                    ▼
Тачка 8 (врх кажипрста)        Тачка 6 (зглоб прста)
  │                                    │
  └──────────────────┬─────────────────┘
                     ▼
             Да ли је y8 < y6?
            (кажипрст испружен)
             ├── НЕ ──► Слободно кретање курсора
             └── ДА ──► АКТИВНО ЦРТАЊЕ
                          ├── Рачунање HSV дугине боје
                          ├── Додавање сјаја у drawing_layer
                          └── Репродукција звука искрица
```

1. **Детекција геста за цртање:**
   - Прати се положај врха кажипрста (тачка 8) и његовог средњег зглоба (тачка 6).
   - Када је $y_8 < y_6$ (врх изнад зглоба), систем активира режим цртања. Када дете спусти прст или савије шаку у песницу, цртање се паузира и курсор се само креће без остављања трага.

2. **Светлећи неонски ефекат (Glow):**
   - Линија се не црта обичном бојом, већ се прави слојевити радијални сјај спајањем тачака кроз засићену HSV палету боја која се континуирано прелива како се рука помера.
   - Спајање са видео снимком ради се помоћу адитивног блендовања: `cv2.add(frame, drawing_layer)`.

3. **Асинхрона обрада за 40+ FPS на Pi 5:**
   - Читање камере (`_cam_worker`) и MediaPipe инференца (`_ai_worker`) раде у две засебне позадинске нити (`threading.Thread`). Главна нит само приказује готов слој на екрану, тако да нема сецкања нити кашњења.

## Додатак: Хардверска надградња са сетом „37 у 1” 🎨✨

Ова игра се на лабораторијском столу лако проширује модулима из сета 37 у 1 за мултисензорно искуство:

1. **RGB LED (KY-016) на GPIO 22 (R), 27 (G), 23 (B)** — **Права дугина лампа:**
   - Хардверска LED диода у реалном времену мења боју и светли тачно оном бојом којом дете у том тренутку црта на екрану.
2. **Пасивна зујалица (KY-006) на GPIO 25** — **Theremin звучни ефекат:**
   - Висина тона зујалице се мења како се кажипрст креће горе-доле по вертикали кадра (низак тон при дну, висок пиштав тон при врху екрана).
3. **Тактилни тастер (KY-004) на GPIO 24** — **Физичко дугме за брисање:**
   - Велико дугме на кутији уређаја којим предшколско дете ресетује цртеж без куцања по тастатури.

```
                  Raspberry Pi 5 GPIO Pinout (Чаробни штапић)
                         ┌──────────────┐
       3.3V Power (Pin 1)│ ●  ● │(Pin 2)  5V Power
                         │ ●  ● │(Pin 6)  GND ────────────► [GND] Заједничка маса
                         │ ●  ● │(Pin 14) GND ────────────► [GND] RGB LED (KY-016)
  [G] Зелена     (Pin 13)│ ●  ● │(Pin 16) GPIO 23 ───────► [B] Плава LED  (KY-016)
  [R] Црвена     (Pin 15)│ ●  ● │(Pin 18) GPIO 24 ───────► [S] Тастер 'Clear' (KY-004)
                         │ ●  ● │(Pin 22) GPIO 25 ───────► [S] Зујалица    (KY-006)
                         └──────────────┘
```

### Пример проширења у Python-у

```python
from gpiozero import RGBLED, Button, TonalBuzzer

led = RGBLED(red=22, green=27, blue=23)
btn_clear = Button(24, pull_up=True)
buzzer = TonalBuzzer(25)

# Физичко дугме брише цртеж
btn_clear.when_pressed = lambda: drawing_layer.fill(0)

# У петљи цртања (RGB усклађен са бојом четкице, тон са висином Y):
def update_hardware_drawing(r, g, b, py, height=480):
    led.color = (r / 255.0, g / 255.0, b / 255.0)
    # Мапирање Y координате (0-480) у музичку фреквенцију
    midi_note = int(60 + (1.0 - py / height) * 24) # C4 до C6
    buzzer.play(midi_note)
```

### Брзи тест на плочи

```bash
python -c "
from gpiozero import RGBLED, Button; import time
led = RGBLED(22, 27, 23); btn = Button(24)
print('Дуга: црвена...'); led.color = (1, 0, 0); time.sleep(0.5)
print('Дуга: зелена...'); led.color = (0, 1, 0); time.sleep(0.5)
print('Дуга: плава...'); led.color = (0, 0, 1); time.sleep(0.5); led.off()
print('Притисни тастер за брисање (KY-004) на GPIO 24...')
if btn.wait_for_press(timeout=4):
    print('Тастер ради! Цртеж обрисан.')
led.close(); btn.close()
"
```
