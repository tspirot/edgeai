# Ухвати звездице — чаробна корпица

![ниво: основно](https://img.shields.io/badge/%D0%BD%D0%B8%D0%B2%D0%BE-%D0%BE%D1%81%D0%BD%D0%BE%D0%B2%D0%BD%D0%BE-2f6fed) ![хардвер: Camera Module 3](https://img.shields.io/badge/%D1%85%D0%B0%D1%80%D0%B4%D0%B2%D0%B5%D1%80-Camera_Module_3-c51a4a) ![Python: 3.9+](https://img.shields.io/badge/Python-3.9%2B-3776ab)

Интерактивна игра брзине и координације за предшколце: дете помера отворену шаку лево-десно у ваздуху, док нацртана корпица верно прати длан и хвата падајуће сјајне звездице и воћкице.

![Ухвати звездице — приказ игре уживо](/slike/primeri/korpica.jpg)

## Покретање

```bash
cd ~/primeri/igrice/korpica
python korpica.py
```
*(или изабери игру [3] у главном менију: `python ~/primeri/igrice/pokretac_igrice.py`)*

## Контроле

- **Померање шаке лево-десно:** Корпица на екрану клизи по хоризонтали пратећи центар длана детета.
- **`[r]`:** Ресетуј резултат и поене (Reset).
- **`[m]`:** Укључи / искључи звук (Mute).
- **`[q]` или `[ESC]`:** Повратак у главни мени.

## Како ради

```text
  Кадар са камере (Picamera2)
             │
             ▼
   MediaPipe Hands (21 тачка шаке)
             │
             ▼
   Центар длана (Landmarks 0 и 9) ──► X координата корпице
                                             │
 ┌───────────────────────────────────────────┴────────────────────────┐
 │ Падајући објекти (звездице и јагоде са симулираном брзином и масом)│
 └───────────────────────────────────────────┬────────────────────────┘
                                             │
                            ┌────────────────┴────────────────┐
                            ▼                                 ▼
                     УХВАЋЕНО У КОРПУ!                     ПРОМАШАЈ
                     ├── Поени +10                         └── Пад испод дна
                     ├── Експлозија златних искрица
                     ├── Синтетизовани тон успеха
                     └── (Опционо) GPIO зелена LED + звук
```

1. **Праћење положаја корпице преко тежишта длана:**
   - Положај корпице се везује за средину длана (просек зглоба руке Landmark 0 и корена средњег прста Landmark 9). Корпица глатко прати само $X$ осу, док је висина корпице фиксирана при дну екрана, што предшколцима олакшава прецизно нишањење без замора руке.

2. **Детекција упада у отвор корпице:**
   - Звездице и јагоде падају различитим брзинама. Када координате објекта уђу у унутрашњи правоугаоник отвора корпе ($x_{k} - w < x_o < x_{k} + w$ и $y_{k} < y_o < y_{k} + h$), објекат се уклања, повећава се бројач уловљених поена и пушта весели зврјећи тон.

3. **Синтетизовани чаробни акорди:**
   - Звук звончића при ухваћеној звездици генерише се математички у Pygame миксеру као суперозиција три синусоидна таласа на 523 Hz, 659 Hz и 784 Hz (дурски акорд C-E-G) без потребе за екстерним звучним фајловима.

## Додатак: Хардверска надградња са сетом „37 у 1” 🧺⭐

1. **RGB LED (KY-016) на GPIO 22, 27, 23:**
   - 🟢 Зелено светло бљесне сваки пут када звездица успешно упане у корпу.
2. **Пасивна зујалица (KY-006) на GPIO 25:**
   - Кратак високи тон (бип) као звучна потврда поготка за децу са оштећењем вида.
3. **Тактилни тастер (KY-004) на GPIO 24:**
   - Ресетовање резултата на велико црвено физичко дугме.

```
                  Raspberry Pi 5 GPIO Pinout (Чаробна корпица)
                         ┌──────────────┐
       3.3V Power (Pin 1)│ ●  ● │(Pin 2)  5V Power
                         │ ●  ● │(Pin 6)  GND ────────────► [GND] Заједничка маса
   [G] Зелена     (Pin 13)│ ●  ● │(Pin 14) GND ────────────► [GND] RGB LED (KY-016)
   [R] Црвена     (Pin 15)│ ●  ● │(Pin 16) GPIO 23 ───────► [B] Плава LED  (KY-016)
                         │ ●  ● │(Pin 18) GPIO 24 ───────► [S] Тастер Reset (KY-004)
                         │ ●  ● │(Pin 22) GPIO 25 ───────► [S] Зујалица    (KY-006)
                         └──────────────┘
```

### Пример проширења у Python-у

```python
from gpiozero import RGBLED, Buzzer, Button
import time

led = RGBLED(red=22, green=27, blue=23)
buzzer = Buzzer(25)
btn_reset = Button(24, pull_up=True)

def on_star_caught():
    led.color = (0, 1, 0)
    buzzer.on()
    time.sleep(0.04)
    buzzer.off()
    led.off()
```
