# Пуцкетање — невидљивост и сегментација

![ниво: средње](https://img.shields.io/badge/%D0%BD%D0%B8%D0%B2%D0%BE-%D1%81%D1%80%D0%B5%D0%B4%D1%9A%D0%B5-2f6fed) ![хардвер: Camera Module 3](https://img.shields.io/badge/%D1%85%D0%B0%D1%80%D0%B4%D0%B2%D0%B5%D1%80-Camera_Module_3-c51a4a) ![Python: 3.9+](https://img.shields.io/badge/Python-3.9%2B-3776ab)

Пуцни прстима у ваздуху и нестани: неуронска мрежа за селфи сегментацију у реалном времену издваја твоју силуету и растапа је у дигиталну прашину, откривајући чисту празну собу у позадини као прави плашт невидљивости.

![Пуцкетање — невидљивост и сегментација](/slike/primeri/pucketanje.jpg)

## Покретање

```bash
cd ~/primeri/pucketanje
python pucketanje.py
```

## Контроле

- **Пуцањ прстима (Snap):** Споји палац и средњи прст, па брзо пуцни да активираш невидљивост.
- **`[Space]`:** Ручно укључивање / искључивање невидљивости преко тастатуре.
- **`[r]`:** Поновно снимање празне позадине (изађи из кадра на 1 секунду).
- **`[n]`:** NoIR баланс боја.
- **`[q]` или `[ESC]`:** Излаз из програма.

## Како ради

```text
  1. Снимање празне собе (Калибрација на тастер [r])
                       │
                       ▼
  2. Улазак особе у кадар са камере
                       │
       ┌───────────────┴───────────────┐
       ▼                               ▼
MediaPipe Hands                 SelfieSegmentation
Праћење шаке за пуцањ           Маска особе (Score > 0.55)
       │                               │
       ▼                               │
Машина стања пуцња:                    │
IDLE ──► READY (палац+средњи)          │
     ──► SNAP! (брзо одвајање)         │
       │                               │
       └───────────────┬───────────────┘
                       ▼
          Окидање ефекта невидљивости:
   np.where(maska_osobe, prazna_soba, kadar)
                       +
   Експлозија 350 честица златне прашине
```

1. **Машина стања детекције пуцкетања:**
   - Алгоритам прати растојање између врха палца (Landmark 4) и средњег прста (Landmark 12).
   - Када су спојени ($d < 25\text{ px}$), систем улази у стање `READY`. Када се у следећем кадру растојање нагло повећа ($d > 0.48 \times \text{дужина длана}$), региструје се успешан пуцањ прстима са заштитом од лажног окидања (Debounce 0.9 s).

2. **Селфи сегментација на уређају:**
   - Модел `SelfieSegmentation` сваком пикселу додељује вероватноћу од 0.0 до 1.0 да припада особи. Прагом од 0.55 прави се бинарна маска која се уклапа са претходно снимљеном чистом позадином собе помоћу векторизоване `np.where` функције.

## Додатак: Хардверска надградња са сетом „37 у 1” 🪄💥

1. **Сензор вибрације / звука (KY-002 или KY-038):**
   - Детектује стварни физички звучни талас или пуцањ прстију за двоструку верификацију (вид + звук).
2. **5V Релеј (KY-019) на GPIO 24:**
   - Механички шкљоцај релеја прати тренутак кад особа „нестане”.
3. **RGB LED (KY-016) на GPIO 22, 27, 23:**
   - Пулсира бело светло током дезинтеграције, а затим се гаси.
