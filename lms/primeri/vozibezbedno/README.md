## Како ради

- EAR (отвореност ока) испод 0,22 дуже од 1,3 s пали аларм за поспаност; MAR изнад 0,55 је зевање.
- PERCLOS је проценат последњих 150 кадрова са склопљеним оком; нагиб главе даје `cv2.solvePnP` на 6 тачака лица.
- **Ово је школски експеримент, не сигурносни уређај:** прагови су подешени за једну камеру и једно лице.

## Додатак: Хардверска надградња са сетом „37 у 1” 🚗💤

У основном примеру аларм се исписује само на екрану — што у реалном возилу нема ефекта јер возач који је заспао има затворене очи. Зато се на плочу повезују физички актуатори из сета „37 у 1”:

1. **Активна зујалица (Buzzer KY-012)** на **GPIO 17**:
   - Оштар акустички аларм који се моментално активира чим EAR падне испод 0,22 дуже од 1,3 s.
2. **RGB LED модул (KY-016)** на **GPIO 27 (G), 22 (R), 23 (B)**:
   - 🟢 **Зелено:** Возач је будан и прати пут (нормалан EAR и MAR).
   - 🟡 **Жуто:** Зевање или пад концентрације (MAR > 0,55).
   - 🔴 **Црвено трепћуће:** Алармантна поспаност (склопљене очи преко 1,3 s).
3. **5V Релеј модул (KY-019)** на **GPIO 24**:
   - Симулација хаптичког аларма (вибрација седишта/волана) или сигурносног укључивања аваројних светала.
4. **Тактилни тастер (KY-004)** на **GPIO 25**:
   - Тастер за потврду будности („Reset/Acknowledge”) на волану којим возач искључује аларм.

```
  Шема везивања на Pi 5:
  ├── Активна зујалица (KY-012) ──► GPIO 17 (Pin 11) + GND (Pin 9)
  ├── RGB LED (KY-016)          ──► R: GPIO 22, G: GPIO 27, B: GPIO 23, GND: Pin 14
  ├── 5V Релеј (KY-019)         ──► IN: GPIO 24, VCC: 5V (Pin 2), GND: Pin 20
  └── Тастер на волану (KY-004) ──► S: GPIO 25, VCC: 3.3V (Pin 1), GND: Pin 6
```

### Брзо проширење у скрипти `vozibezbedno.py` (пример за ученике)

Ученици на крају радионице могу на почетак `vozibezbedno.py` додати:
```python
from gpiozero import Buzzer, RGBLED, OutputDevice

buzzer = Buzzer(17)
led = RGBLED(red=22, green=27, blue=23)
relay = OutputDevice(24)

# У главној petlji када се детектује поспаност:
if alarm_pospanost:
    buzzer.on()
    led.color = (1, 0, 0)
    relay.on()
elif alarm_zevanje:
    buzzer.off()
    led.color = (1, 0.7, 0)
    relay.off()
else:
    buzzer.off()
    led.color = (0, 1, 0)
    relay.off()
```
