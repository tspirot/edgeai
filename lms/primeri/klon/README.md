# Клон — цело тело, лице, шаке и осећања

![ниво: напредно](https://img.shields.io/badge/%D0%BD%D0%B8%D0%B2%D0%BE-%D0%BD%D0%B0%D0%BF%D1%80%D0%B5%D0%B4%D0%BD%D0%BE-2f6fed) ![хардвер: Camera Module 3](https://img.shields.io/badge/%D1%85%D0%B0%D1%80%D0%B4%D0%B2%D0%B5%D1%80-Camera_Module_3-c51a4a) ![Python: 3.9+](https://img.shields.io/badge/Python-3.9%2B-3776ab)

Подељен екран (Split-screen): лево стварна слика са камере са скелетима тела, лица и шака, а десно твој дигитални клон (Cyber Avatar, фото-клон Николе Тесле или зелени Матрикс) који у реалном времену реплицира твоје покрете и препознаје осећања (срећа, изненађење, неутрално).

![Клон — цело тело, лице и осећања](/slike/primeri/klon.jpg)

## Покретање

```bash
cd ~/primeri/klon
python klon.py
```

## Контроле

- **`[s]`:** Смена модела клона (Cyber Avatar → Фото-клон Тесле → Дигитални Матрикс).
- **`[q]` или `[ESC]`:** Излаз из апликације.

## Како ради

```text
       Слика са камере (Picamera2 RGB888)
                       │
       ┌───────────────┼───────────────┐
       ▼               ▼               ▼
 MediaPipe Pose   Face Mesh 468   MediaPipe Hands
 (33 тачке тела)  (мимика лица)   (21 тачка по шаци)
       │               │               │
       └───────────────┼───────────────┘
                       ▼
       ┌───────────────────────────────┐
       │ Геометријска анализа осећања: │
       │ • Однос ширине уста и очију   │
       │ • Подигнутост углова усана    │
       │ • Отвореност уста (MAR)       │
       └───────────────┬───────────────┘
                       │
       ┌───────────────┴───────────────┐
       ▼                               ▼
 ЛЕВИ ПАНЕЛ:                     ДЕСНИ ПАНЕЛ:
 Стварни кадар са скелетом       Дигитални сајбер клон
 и исписом емоције               (Тесла / Матрикс / Аватар)
```

1. **Адаптивно праћење („далеко“ против „близу“):**
   - Када си удаљен од камере, доминантан је `MediaPipe Pose` модел који прати пуну кинематику кичме, руку и ногу. Када приђеш ближе, активирају се детаљни `FaceMesh` (са 468 тачака) и `Hands` за прсте.

2. **Математика осећања без тешког модела:**
   - Уместо спорог класификатора осећања, функција `analyze_emotions` користи чисту геометрију:
     - **Осмех:** Растојање углова усана (Landmarks 61 и 291) према размаку зеница. Ако се углови подигну према јагодицама, региструје се срећа.
     - **Изненађење:** Растојање између горње и доње усне прелази праг уз широм отворене очи.

## Додатак: Хардверска надградња са сетом „37 у 1” 🤖💡

1. **RGB LED (KY-016) на GPIO 22, 27, 23 — Емоционално светло:**
   - 🟢 **Зелено:** Срећан / насмејан.
   - 🔵 **Плаво:** Миран / неутралан.
   - 🟡 **Жуто/Црвено:** Изненађен / широм отворена уста.
2. **Пасивна зујалица (KY-006) на GPIO 25:**
   - Кратак тон при промени режима приказа на тастер `[s]`.
