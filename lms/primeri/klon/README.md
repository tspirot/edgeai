Подељен екран: лево стварна слика, десно дигитални клон који понавља твоје покрете.

## Покретање

```bash
cd ~/primeri/klon
python klon.py
```

**Тастери:** [s] смена модела · [q] излаз

## Како ради

- Режим „далеко“ прати цело тело; режим „близу“ прати лице, шаке и прсте.
- Осећања (`analyze_emotions`) се рачунају геометријом лица (ширина уста према размаку очију, подигнутост углова, отвореност уста), без посебног модела — зато су осетљива на камеру и светло.
- Тастер `[s]` мења десни приказ: Cyber Avatar, фото-клон Николе Тесле (лице се деформише по твом) и Матрикс.
- Слике `tesla.jpg` и `einstein.jpg`: извор и лиценца су отворено питање (види `../../../CREDITS.md`).
