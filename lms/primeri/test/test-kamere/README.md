# Провера камере: Camera Module 3 (IMX708)

![ниво: основно](https://img.shields.io/badge/%D0%BD%D0%B8%D0%B2%D0%BE-%D0%BE%D1%81%D0%BD%D0%BE%D0%B2%D0%BD%D0%BE-2f6fed) ![хардвер: Camera Module 3](https://img.shields.io/badge/%D1%85%D0%B0%D1%80%D0%B4%D0%B2%D0%B5%D1%80-Camera_Module_3-c51a4a) ![Python: 3.9+](https://img.shields.io/badge/Python-3.9%2B-3776ab)

Брзи хардверски дијагностички тест за Raspberry Pi 5 и сензор Sony IMX708: иницијализује камеру преко нативног `Picamera2` стека, снима један кадар, исписује тачне димензије низа и рачуна средње вредности свих боја.

![Провера камере — хардверска дијагностика](/slike/primeri/test-kamere.jpg)

## Покретање

```bash
cd ~/primeri/test
python check_cam.py
```

## Како ради

```text
  Raspberry Pi 5 CSI-2 порт
             │
             ▼
     Sony IMX708 сензор (Camera Module 3)
             │
             ▼
  Picamera2 preview konfiguracija:
  size: (640, 480), format: RGB888
             │
             ▼
  arr = p.capture_array()
             │
   ┌─────────┴────────────────────────┐
   ▼                                  ▼
Облик низа: (480, 640, 3)     Просек боја по каналима:
                              Канал 0 (B): arr[:,:,0].mean()
                              Канал 1 (G): arr[:,:,1].mean()
                              Канал 2 (R): arr[:,:,2].mean()
```

1. **Дијагностика CSI везе:**
   - Камера је повезана танким флекс каблом са 15/22 пина на CAM0 или CAM1 порт плоче. Овај тест одмах открива ако кабл није добро постављен или сензор нема напајање.

2. **Равнотежа беле боје (White Balance):**
   - Анализом средњих вредности канала утврђује се осветљеност просторије: ако су сви канали близу 0, сокило камере је поклопљено или је у соби мрак; ако су близу 255, слика је преекспонирана.

## Вежба за ученике

1. Прекријте сочиво камере руком и покрените скрипту — колике су вредности канала?
2. Уперите камеру у бело светло или папир и упоредите просек црвене и плаве боје.
