Комплетан тест MediaPipe Hands неуронске мреже: прати до 2 руке у кадру (21 тачка по руци), аутоматски броји подигнуте прсте сваке шаке, црта динамички правоугаоник распона између палчева и кажипрста обе руке и омогућава контролу засићења и NoIR филтера.

![Препознавање руку: MediaPipe Hands](/slike/primeri/prepoznavanje-ruku.jpg)

## Покретање

```bash
cd ~/primeri/test
python proba.py
```

## Контроле

- **`[n]`:** Укључи / искључи NoIR корекцију боја за инфрацрвене камере.
- **`[+]` / `[-]`:** Повећај или смањи засићеност боја кадра (Saturation).
- **`[q]` или `[ESC]`:** Излаз из програма.

---

## Како ради

```text
       Слика са камере (640x480 RGB)
                    │
                    ▼
          MediaPipe Hands модел
                    │
                    ▼
          21 кључна тачка по шаци
                    │
      ┌─────────────┴─────────────┐
      ▼                           ▼
Бројање прстију           Дворучни правоугаоник
y_tip < y_pip?            P1 = (min(x_levo), min(y_levo))
(палац, кажипрст,         P2 = (max(x_desno), max(y_desno))
 средњи, домали, мали)    Цртање жутог оквира распона
```

1. **21 тродимензионални Landmark:**
   - Модел враћа релативне координате $(x, y, z)$ нормализоване на интервал $[0.0, 1.0]$. За тачну позицију на екрану, $X$ се множи са ширином кадра (640), а $Y$ са висином (480).

2. **Логика бројања подигнутих прстију:**
   - За кажипрст, средњи, домали и мали прст пореди се $Y$ координата врха (Landmarks 8, 12, 16, 20) са средњим зглобом (Landmarks 6, 10, 14, 18). Пошто $Y$ оса на екрану расте надоле, услов $y_{\text{tip}} < y_{\text{pip}}$ значи да је прст испружен нагоре!

## Вежба за ученике

1. Подигните само кажипрст и мали прст („рокенрол“ гест) — пратите испис бројача.
2. Промените праг поверења детекције (`min_detection_confidence`) са 0.6 на 0.8 и упоредите стабилност праћења при брзим покретима.
