# AR хемија — цепање и спајање атома

![ниво: напредно](https://img.shields.io/badge/%D0%BD%D0%B8%D0%B2%D0%BE-%D0%BD%D0%B0%D0%BF%D1%80%D0%B5%D0%B4%D0%BD%D0%BE-2f6fed) ![хардвер: Camera Module 3](https://img.shields.io/badge/%D1%85%D0%B0%D1%80%D0%B4%D0%B2%D0%B5%D1%80-Camera_Module_3-c51a4a) ![Python: 3.9+](https://img.shields.io/badge/Python-3.9%2B-3776ab)

Проширена стварност (AR) на уређају: рукама у ваздуху бираш елементе из Periodnog система, хваташ атоме штипањем прстију, цепаш хемијске везе развлачењем обема рукама и спајаш атоме у нове молекуле уз физику опруга, специјалне ефекте и звуке.

![АР хемија — цепање и спајање атома](/slike/primeri/hemija.jpg)

## Покретање

```bash
cd ~/primeri/hemija
python hemija.py
```

## Контроле

- **Штипање прстима (Pinch):** Палац и кажипрст ближи од 46 пиксела хватају атом и превлаче га по кадру.
- **Цепање везе са обе руке:** Ухвати по један атом са обе руке и развуци их на супротне стране док веза не пукне уз звучни ефекат!
- **Принос атому:** Принеси атоме један другом да се споје по правилима хемијских валенци.
- **`[1–6]` Брзи експерименти и молекули:**
  - `[1]` Вода ($2\text{H} + \text{O} \rightarrow \text{H}_2\text{O}$)
  - `[2]` Угљен-диоксид ($\text{C} + 2\text{O} \rightarrow \text{CO}_2$)
  - `[3]` Кухињска со ($\text{Na} + \text{Cl} \rightarrow \text{NaCl}$)
  - `[4]` Метан ($\text{C} + 4\text{H} \rightarrow \text{CH}_4$)
  - `[5]` Амонијак ($\text{N} + 3\text{H} \rightarrow \text{NH}_3$)
  - `[6]` Хлороводоник ($\text{H} + \text{Cl} \rightarrow \text{HCl}$)
- **`[p]`:** Отвори / затвори Периодни систем елемената.
- **`[r]` или `[Space]`:** Ресетуј експеримент.
- **`[m]`:** Звук укључивање / искључивање.
- **`[q]` или `[ESC]`:** Излаз.

## Додатак: Хардверска надградња са сетом „37 у 1” 🧪⚡

1. **5V Релеј (KY-019) на GPIO 24 — Реакциона капија:**
   - Окида механички клик при сваком успешном спајању молекула воде или соли.
2. **RGB LED (KY-016) на GPIO 22, 27, 23:**
   - Светли у боји тренутно ухваћеног хемијског елемента (црвено за кисеоник, бело/плаво за водоник, жуто за натријум, зелено за хлор).
3. **Пасивна зујалица (KY-006) на GPIO 25:**
   - Производи кратак пад фреквенције при пуцању везе и трогласни акорд при синтези.
