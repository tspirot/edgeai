# AR хемија — цепање и спајање атома

![ниво: напредно](https://img.shields.io/badge/%D0%BD%D0%B8%D0%B2%D0%BE-%D0%BD%D0%B0%D0%BF%D1%80%D0%B5%D0%B4%D0%BD%D0%BE-2f6fed) ![хардвер: Camera Module 3](https://img.shields.io/badge/%D1%85%D0%B0%D1%80%D0%B4%D0%B2%D0%B5%D1%80-Camera_Module_3-c51a4a) ![Python: 3.9+](https://img.shields.io/badge/Python-3.9%2B-3776ab)

Проширена стварност у ваздуху: бираш елементе, хваташ атоме штипањем, цепаш везе и правиш молекуле.

## Покретање

```bash
cd ~/primeri/hemija
python hemija.py
```

**Тастери:** [p] периодни систем · [1–6] експерименти · [r] ресет · [q] излаз

## Како ради

- Штипање (палац + кажипрст ближи од 46 пиксела) „држи“ атом; са обе руке се веза развлачи док не пукне.
- Спајање иде по валенцама; препознаје воду (H₂O), угљен-диоксид, кухињску со, метан, амонијак и хлороводоник, свака са својим ефектом и звуком.
- Тастери `[1]`–`[6]` покрећу експерименте, `[p]` периодни систем, `[r]`/`[Space]` ресет, `[m]` звук.
