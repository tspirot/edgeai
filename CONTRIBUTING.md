# Како да допринесеш

Овај репо воде наставници и ученици Техничке школе Пирот.

1. Направи грану (`git checkout -b моја-измена`), не ради директно на `main`:
   сваки пуш у `main` објављује сајт.
2. Сајт: `cd web && npm install && npm run dev`, па `npm run build` пре комита.
3. Пројекти: у фолдеру пројекта `pip install -e ".[dev]" && pytest`.
4. Језик: садржај сајта је на **ћирилици**, имена фајлова и променљивих на
   латиници без дијакритика (`kamera_i_slika.py`, `slug-ovi-sa-crticom`).
5. Нови материјал трећих страна (слике, модели, подаци) пријави у `CREDITS.md`
   са извором и лиценцом. Ако нема дозволе, не иде у репо.
6. Не комитуј: лозинке и токене, снимке лица или гласа ученика, велике бинарне
   фајлове (>1 MB), `.venv`, `node_modules`.
7. Опиши измену једном-две реченице у поруци комита.
